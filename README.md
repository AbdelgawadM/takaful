# تكافل — إعادة تصميم الواجهة الأمامية (Frontend Prototype)

نموذج واجهة أمامية كامل ومتجاوب لمنصة **تكافل** — بوابة الوصول الصحي الذكية — مبني وفق
«كتاب المشروع الشامل» وموجه العمل المعتمد. **واجهة فقط: لا يوجد أي منطق خلفي، كل البيانات تجريبية.**

## الهوية

- **اللوجو الرسمي**: `assets/img/logo.png` (تكافل العربية للرعاية الصحية) — تُستخدم نسخة بيضاء تلقائيًا على الخلفيات الداكنة عبر الكلاس `logo-invert`.
- **الألوان**: كحلي أساسي `#1A4397` + سماوي ثانوي `#05AAE0` مأخوذة من اللوجو، معرفة في `tokens.css`.
- **الخط**: itf Ghroob Arabic (خمسة أوزان، ملفات محلية في `assets/fonts/`) مع IBM Plex Sans Arabic كخط احتياطي.

## التشغيل

لا يحتاج أي أدوات بناء. افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> يفضَّل الخادم المحلي حتى يعمل خط IBM Plex Sans Arabic من Google Fonts وتنتقل الصفحات بروابطها.

## البنية

```
assets/
  css/
    tokens.css       ← نظام التصميم المركزي (ألوان، مسافات، ظلال، حركة، خط)
    base.css         ← إعادة الضبط، الطباعة، الهيدر/الفوتر/الشريط السفلي/الدرج، أساسيات الحركة
    components.css   ← المكونات: بطاقات، شارات، نماذج، مودال، توست، سكيلتون، حالات…
    pages.css        ← تكوينات الصفحات (هيرو، خريطة، ريلز، دفع، بوابات…)
  js/
    data.js          ← طبقة البيانات التجريبية (مراكز، خدمات، عروض، ريلز، قسائم…)
                        بنفس الأشكال المتوقعة من الـ API مستقبلًا — تُستبدل مباشرة
    app.js           ← حقن الهيكل المشترك، الأيقونات، البحث، التوست، كشف الأوفلاين،
                        Scroll-reveal، مولّد QR الشكلي، بطاقات المراكز/الخدمات/العروض
```

## قرارات منفذة من كتاب المشروع

- الشريط السفلي (جوال): الرئيسية | الأقرب | **Reels في المنتصف** | بطاقتي | المزيد.
- البطاقة على بعد نقرة واحدة من أي شاشة (هيدر + شريط سفلي + شريط الرئيسية).
- كل بطاقة مركز تُظهر نوع المنفعة قبل فتحها (خصم فوري / سعر نهائي).
- «اشترِ خدمة» متاح دون عضوية؛ الشرط الوحيد قبل الدفع هو الدخول والتحقق من الجوال.
- سجل حالات القسيمة: جاهزة، محجوزة، مستخدمة، منتهية، ملغاة، قيد النزاع — لكل حالة واجهة.
- التوفير المعروض «موثق فقط» ولا توجد أرقام تقديرية.
- موافقات منفصلة (شروط/موقع/تنبيهات/تسويق) وضوابط عدم الإزعاج ظاهرة في الواجهة.
- حالات إلزامية لكل شاشة: Skeleton بدل المؤشر العام، فراغ بإجراء، خطأ بإعادة محاولة،
  صلاحية مرفوضة بشرح، جلسة منتهية دون فقد السلة، شريط أوفلاين تلقائي، وعلامة «آخر تحديث».

## ملاحظات تقنية

- **RTL أولًا**: خصائص CSS منطقية (`inset-inline`, `margin-inline`…) والبنية جاهزة لإضافة LTR/الإنجليزية.
- **الحركة**: نظام موحد (توقيتات وإيقاعات في `tokens.css`) مع احترام `prefers-reduced-motion` بالكامل.
- **الوصولية**: HTML دلالي، تنقل لوحة مفاتيح (جرّب `/` للبحث و`Esc` للإغلاق)، حالات focus واضحة، تباين جيد، `aria` حيث يلزم.
- **الصور**: لا صور خارجية — رسوم SVG توليدية وأيقونات مضمنة، فتعمل الواجهة دون اتصال ودون حقوق صور.
- **QR والخرائط والدفع وOTP**: عناصر شكلية للعرض فقط — أي إدخال مقبول ولا تحدث أي عمليات حقيقية.
